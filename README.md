# フレイルDX 問診レポートシステム（Web配信版）

釧路孝仁会記念病院 高度健診センター／フレイル健診で使用する、iPad向けの問診・結果レポートシステムです。

## このリポジトリについて

- 中身は **index.html 1ファイルで完結する静的Webアプリ**です。サーバー処理・データベースはありません。
- **受診者データは端末（iPad）のブラウザ内（localStorage）にのみ保存されます。** インターネットへ送信される情報は一切ありません。
- Chart.js / jsPDF / html2canvas は index.html に同梱済みで、実行時に外部へ通信しません。
- Service Worker により、**一度開けば以後はオフライン（圏外）でも起動**します。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（v12 + Web配信パッチ v12w） |
| `manifest.webmanifest` | ホーム画面追加用の設定 |
| `sw.js` | オフライン動作用 Service Worker |
| `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` | アイコン |
| `.nojekyll` | GitHub Pages のビルド処理を無効化 |

## 更新のしかた

1. 新しい `index.html` をこのリポジトリにアップロードして上書きする
2. `sw.js` の `const CACHE = 'frail-dx-v1';` の数字を1つ上げる（例：`v2`）
3. iPadをWi-Fiに繋いだ状態でアプリを開き直す → 自動で新版に切り替わります

## パスコード

`index.html` の冒頭付近、`var PASSCODE = '1989';` の4桁を書き換えると変更できます。
（誤アクセス防止のための簡易ゲートであり、暗号的な認証ではありません）
